# 🕌 Tabligh

### بَلِّغُوا عَنِّي وَلَوْ آيَةً
_"بلّغوا عني ولو آية."_ — النبي محمد ﷺ (البخاري)

**توليد تلقائي لمقاطع (ريلز) قرآنية سينمائية متزامنة على طريقة الكاريوكي ونشرها على تيك توك وإنستغرام وفيسبوك ويوتيوب — وفق جدول زمني، ودون تدخل يدوي.**

لا تختر شيئاً. يقوم مجدوِل باختيار سورة ومقطع عشوائياً، ويجلب التلاوة بدقة، ويصيّر فيديو عمودياً مع إبراز كلمة بكلمة فوق خلفية هادئة، وينشره عدة مرات في اليوم.

## ✨ الميزات

- 🎬 **مقاطع سينمائية بدقة 1080×1920** — خلفية صورة أرشيفية ملء الشاشة (Pexels/Unsplash) مع طبقة تغطية قوية لوضوح القراءة، وجزيئات منسابة خفيفة، وحركة انزلاق بطيئة على طريقة كِن بيرنز.
- 🎨 **ثلاثة قوالب بصرية** — **classic** (صورة + طبقة تعتيم)، و**glass** (بطاقة زجاجية مصنفرة دائمة واحدة مع موجة صوتية حية)، و**noor** ("النور الإلهي" الدافئ — هالة ذهبية + أرقام مذهّبة). اضبط `TEMPLATE` أو بدّله من اللوحة/القائمة.
- 🕋 **مقدمة البسملة** — أي مقطع يبدأ من الآية 1 يُفتَح دوماً ببسملة القارئ نفسه (مُتلوّة بصوته)؛ ويمكن اختيارياً إضافتها قبل *كل* مقطع (`BASMALA=always`). سورتا التوبة والفاتحة تُعالَجان بشكل صحيح.
- 🎤 **تعبئة الكلمات على طريقة الكاريوكي** — تضيء كل كلمة بتزامن مع التلاوة (من اليمين إلى اليسار)، ليتابع المشاهدون معها.
- 🖋️ **طباعة عربية أصيلة** — نص عثماني كامل بالشكل الصحيح بخط **Mada** العصري الأنيق؛ والعناوين بخط الرقعة **Aref Ruqaa**.
- 🎯 **تزامن دقيق، بلا ذكاء اصطناعي** — يأتي الصوت من [everyayah.com](https://everyayah.com) كملفات لكل آية، فيكون توقيت كل آية دقيقاً ومجانياً (دون تفريغ صوتي).
- 🔀 **اختيار تلقائي للمحتوى** — سورة عشوائية + مقطع متتالٍ عشوائي (بطول قابل للضبط)؛ والسور القصيرة تُصيَّر كاملة.
- 🌇 **خلفيات آمنة وراقية** — مجموعة منتقاة من 50 كلمة مفتاحية (مساجد، طبيعة، بحر، سماء…) بالإضافة إلى مرشّح يستبعد أي صورة تحتوي على أشخاص أو أي شيء غير مناسب. اختر مصدرك: **Pexels أو Unsplash أو مجلد صورك المحلي الخاص**.
- 🖥️ **مركز قيادة تفاعلي** — شغّل `tabligh` (دون معاملات) للحصول على واجهة طرفية مذهلة لتوليد المقاطع، وبدء/إيقاف اللوحة، وإدارة قائمة الانتظار، وتصفّح السجل، وتحرير الإعدادات، وإجراء فحص صحة. مترجمة إلى EN/AR/FR.
- 🎞️ **خاتمة مميزة** — يتلاشى المقطع وتنزلق صلاة (مع شعارك) صعوداً فوق المشهد نفسه، ثم يتلاشى الفيديو بأكمله إلى الأسود.
- 📤 **نشر متعدد المنصات** — تيك توك، وإنستغرام ريلز، وفيسبوك ريلز، ويوتيوب شورتس عبر [Buffer](https://buffer.com)، ويُفعَّل لكل منصة على حدة عبر متغيرات البيئة.
- 🎛️ **لوحة تحكم ذاتية الاستضافة** — واجهة ويب محمية بكلمة مرور لإدارة كل إعداد، وتوليد/معاينة/نشر مقطع، وجدولة المقاطع، وتصفّح السجل + التحليلات — كل ذلك مباشرةً، دون إعادة نشر. مترجمة (EN/AR/FR، مع دعم كامل للاتجاه من اليمين إلى اليسار).
- ⏰ **مجدوِل اضبطه وانسَه** — عملية دائمة التشغيل تنشر N مرة في اليوم حسب منطقتك الزمنية.
- 🧹 **صديق للقرص** — تُمحى الملفات المحلية فور النشر؛ وتُشذَّب كائنات السحابة تلقائياً.
- 🐳 **نشر بحاوية واحدة** — Dockerfile + يعمل بشكل رائع على Coolify أو Fly أو Railway أو أي مضيف Docker.

## 🚀 البدء السريع (محلياً)

المتطلبات: **Node ≥ 20** و**ffmpeg** ضمن مسار PATH لديك. (يُنزَّل Chromium تلقائياً بواسطة Puppeteer.)

```bash
git clone https://github.com/911RS/tabligh.git
cd tabligh
npm install
cp .env.example .env        # fill in what you need (see below)

# Render a specific passage to work/…/reel.mp4 (no publishing)
npm start render -- --surah 112 --from 1 --to 4 --reciter husary --translation en.sahih

# Render a random passage
npm start random

# Everything the CLI can do
npm start
```

يظهر ملف `reel.mp4` الجاهز (بالإضافة إلى ملف التوقيت `ir.json`) في `work/<surah>_<range>_<reciter>__<tag>/`.

## ⚙️ الإعداد

كل شيء مُدار عبر متغيرات البيئة (`.env`). جميعها اختيارية إلا حيث تحتاج ميزة ما إلى مفتاح.

| المتغير | الغرض | القيمة الافتراضية |
|---|---|---|
| `TEMPLATE` | النمط البصري للمقطع: `classic` / `glass` / `noor` | `classic` |
| `BASMALA` | مقدمة البسملة: `off` (فقط عند الآية 1) / `always` (كل مقطع) | `off` |
| `BACKGROUND_SOURCE` | `auto` / `pexels` / `unsplash` / `local` | `auto` |
| `BACKGROUND_LOCAL_DIR` | مجلد صورك العمودية الخاصة (عندما يكون المصدر = `local`) | _(فارغ)_ |
| `PEXELS_API_KEY` / `UNSPLASH_ACCESS_KEY` | خلفيات صور أرشيفية | _(غير مضبوط ← تدرّج لوني احتياطي)_ |
| `BUFFER_ACCESS_TOKEN` | رمز واجهة برمجة تطبيقات Buffer للنشر | _(غير مضبوط ← لا نشر)_ |
| `BUFFER_TIKTOK_CHANNEL_IDS` | معرّفات قنوات تيك توك مفصولة بفواصل | _(فارغ)_ |
| `BUFFER_INSTAGRAM_CHANNEL_IDS` | معرّفات قنوات إنستغرام ريلز | _(فارغ)_ |
| `BUFFER_FACEBOOK_CHANNEL_IDS` | معرّفات قنوات فيسبوك ريلز | _(فارغ)_ |
| `BUFFER_YOUTUBE_CHANNEL_IDS` | معرّفات قنوات يوتيوب شورتس | _(فارغ)_ |
| `MINIO_*` | تخزين متوافق مع S3 (دلو عام يجلب منه Buffer) | الدلو `tabligh`، المنفذ `9000` |
| `TZ` / `PUBLISH_TIMES` | المنطقة الزمنية + أوقات اليوم للنشر التلقائي | `Africa/Tunis` / `07:00,13:00,19:00` |
| `KARAOKE_ENABLED` | تعبئة كلمة بكلمة متزامنة مع التلاوة | `true` |
| `TEXT_FILL_COLOR` | لون النص المُتلوّ (المُعبَّأ) | `#ffffff` |
| `WATERMARK_ENABLED` / `WATERMARK_HANDLE` | علامة مائية للشعار في الزاوية (`assets/logo.png`) | `true` / _(فارغ)_ |
| `FULL_SURAH_MAX_AYAHS` | السور بهذا القِصر تُصيَّر كاملة | `7` |
| `RANDOM_MIN_AYAHS` / `RANDOM_MAX_AYAHS` | طول المقطع في الوضع العشوائي | `5` / `10` |
| `MAX_VIDEO_SECONDS` | حد أقصى لطول التلاوة (باستثناء الخاتمة)؛ يقتطع الآيات الأخيرة لتلائم الحد (يتجاوز الحد الأدنى) | `0` _(بلا حد)_ |
| `RETENTION_DAYS` / `MINIO_RETENTION_HOURS` | نوافذ التنظيف | `7` أيام / `24` ساعة |
| `PORT` / `TRIGGER_TOKEN` | خادم HTTP + السر لنقطة نهاية التشغيل | `1998` / _(غير مضبوط ← معطّل)_ |
| `PANEL_ENABLED` | تقديم لوحة التحكم (`false` = بلا واجهة، المجدوِل فقط) | `true` |
| `UI_LANG` | لغة القائمة الطرفية التفاعلية (`en` / `ar` / `fr`) | `en` |

راجع [`.env.example`](.env.example) للقائمة الكاملة الموثّقة. **تبذر هذه القيم المخزن عند أول تشغيل فقط** — بعد ذلك، أدِر الإعدادات مباشرةً في اللوحة أو في قائمة `tabligh`.

**القرّاء:** `husary`، `minshawy`، `abdulbasit`، `hudhaify`، `ayyoub`، `shuraym`، `husary-muallim`، `tunaiji` — أو أي مجلد [everyayah](https://everyayah.com) خام. راجع [`src/quran/reciters.ts`](src/quran/reciters.ts).

**الترجمات:** أي معرّف إصدار من [alquran.cloud](https://alquran.cloud)، مثل `en.sahih`، `fr.hamidullah`، أو `""` للعربية فقط.

## 🖥️ مركز القيادة التفاعلي

شغّل **`tabligh`** دون معاملات في الطرفية لفتح القائمة التفاعلية — مركز تحكم قائم بذاته لكل شيء:

<div align="center">
  <img src="docs/screenshots/cli-command-center.jpg" width="720" alt="مركز القيادة التفاعلي لـ Tabligh — واجهة طرفية بنمط رئيسي-تفصيلي مع لافتة متدرجة اللون وحالة حية وقائمة ولوحة عمل"/>
</div>

```
tabligh                 # opens the menu (in a TTY)
```

- **توليد مقطع** — عشوائي أو اختر مقطعاً؛ يصيّر محلياً (مع تقدّم حي)، ثم يعرض فتح الفيديو أو نشره.
- **انشر الآن** — توليد + نشر في خطوة واحدة.
- **لوحة التحكم** — **بدء / إيقاف / إعادة تشغيل** لوحة الويب كخدمة في الخلفية، أو **فتحها** في متصفحك، أو **تتبّع سجلّاتها** — دون عملية منفصلة تحتاج إلى مراقبة.
- **قائمة الانتظار** — إضافة/إزالة مقاطع يشغّلها المجدوِل قبل الاختيارات العشوائية.
- **السجل والتحليلات** — الإجماليات، والتفصيل حسب المنصة، والمنشورات الأخيرة.
- **الإعدادات** — اللغة، ومصدر الخلفية (بما في ذلك المجلد المحلي)، وتشغيل/إيقاف المجدوِل، والجدول، والمحتوى، والقنوات، ومفاتيح واجهة برمجة التطبيقات — كلها تُطبَّق مباشرةً.
- **الطبيب (Doctor)** — فحص صحة بنظرة واحدة (ffmpeg، وChrome، والمفاتيح، والتخزين، والقرص).

مترجمة إلى **English / العربية / Français** (اضبط `UI_LANG` أو بدّلها في الإعدادات). السياقات غير التفاعلية (الأنابيب، وDocker، وCI) تطبع المساعدة الكلاسيكية بدلاً من ذلك، فلا تتأثر البرمجة النصية. يوجد أيضاً `tabligh menu` (لفرضها) و`tabligh doctor` (لتشغيل فحص الصحة فقط).

## 🎛️ لوحة تحكم الويب وواجهة سطر الأوامر

افتح جذر التطبيق (`http://localhost:1998`) للحصول على لوحة محمية بكلمة مرور:

- **أول تشغيل** يعرض شاشة إعداد لإنشاء كلمة مرورك (أو شغّل `tabligh init` لمعالج طرفي — وهو الآن ينتهي بعرض عنوان لوحة معلوماتك وعرض بدء اللوحة).
- **لوحة المعلومات** — الحالة، و*توليد الآن* / *+ نشر* بنقرة واحدة، وأحدث معاينة.
- **التوليد** — اختر مقطعاً أو اذهب عشوائياً، عاينه قبل نشره.
- **الإعدادات** — الجدول (المنطقة الزمنية + منتقي الوقت)، والمحتوى (الترجمة، وعدد الآيات، و**الحد الأقصى للطول**)، والعلامة التجارية (الكاريوكي، ولون التعبئة، والجزيئات، والخلفية المتحركة، وترويج الخاتمة)، ومعرّفات قنوات المنصات، ومفاتيح واجهة برمجة التطبيقات والتخزين — تُطبَّق **مباشرةً**.
- **قائمة الانتظار** — خطّط لمقاطع محددة؛ يشغّلها المجدوِل قبل الاختيارات العشوائية.
- **السجل / التحليلات** — كل تصيير + نشر، والإجماليات، والتفصيل حسب المنصة، والسجلّات الأخيرة.
- **اللغة** — بدّل اللوحة بين English والعربية (من اليمين إلى اليسار) وFrançais.

تسجيل الدخول محدود المعدّل (5 محاولات ← قفل لمدة 15 دقيقة). أعد تعيين كلمة المرور من الخادم عبر
`tabligh set-password <new>` (مثال: `docker exec <container> tabligh set-password …`).

تعيش الإعدادات في المخزن وتستمر على وحدة التخزين `/app/data`؛ و`.env` يبذرها فقط عند أول تشغيل.

### 🌐 الوصول إلى اللوحة

ليس للتطبيق نطاق خاص به — إنه فقط يستمع على منفذ (**`1998`** افتراضياً، تجاوزه عبر `PORT`) على جميع الواجهات. يعتمد العنوان الذي تفتحه على مكان تشغيله:

| مكان التشغيل | العنوان الذي تفتحه | HTTPS؟ |
|---|---|---|
| حاسوبك الخاص (`npm` / محلي) | `http://localhost:1998` | — (محلي، لا بأس) |
| خادم افتراضي سحابي، منفذ خام مكشوف | `http://<your-server-ip>:1998` | ❌ **لا** |
| خادم افتراضي خلف وكيل عكسي | `https://yourdomain.com` | ✅ الوكيل يوفّره |

- **محلياً**، يطبع معالج الإعداد الرابط الدقيق عند البدء (`http://localhost:1998`).
- **على خادم افتراضي**، يتطلب الوصول إلى `http://<server-ip>:1998` أيضاً أن يسمح جدار الحماية / مجموعة الأمان لديك بالدخول عبر المنفذ `1998`.
- **⚠️ لا تترك المنفذ الخام مكشوفاً على الإنترنت.** تقدّم اللوحة HTTP عادياً، فستنتقل كلمة مرور تسجيل دخولك دون تشفير. ضعها خلف وكيل عكسي ينهي TLS:
  - **[Coolify](https://coolify.io)** (موصى به) — عيّن نطاقاً للتطبيق ووجّهه إلى المنفذ `1998`؛ يتولّى Traefik الخاص بـ Coolify التوجيه **و**شهادة Let's Encrypt تلقائياً.
  - **Nginx / Caddy** — `proxy_pass http://127.0.0.1:1998` خلف نطاقك + الشهادة.

لا يحتاج التطبيق أبداً إلى معرفة نطاقه العام؛ فالوكيل يملك النطاق وHTTPS ويعيد التوجيه إلى `1998` داخلياً.

## 📤 النشر

يمرّ النشر عبر [Buffer](https://buffer.com)، الذي يوزّعه على كل منصة متصلة.

1. أنشئ حساب Buffer واربط قنوات تيك توك / إنستغرام / فيسبوك / يوتيوب لديك.
2. اضبط `BUFFER_ACCESS_TOKEN`، ثم شغّل `npm start channels` لسرد معرّفات قنواتك.
3. ضع المعرّفات في متغيرات `BUFFER_*_CHANNEL_IDS` المطابقة (أي مجموعة جزئية — تيك توك فقط يكفي).
4. `npm start random -- --publish` (أو دع المجدوِل يفعل ذلك).

تحصل كل منصة على التنسيق الصحيح تلقائياً (Reel / Short). يتضمن التعليق السورة، ونطاق الآيات، والقارئ، ونسبة الصورة، والوسوم.

### التخزين — لست بحاجة إلى تثبيت MinIO

يُستخدَم تخزين الكائنات **للنشر فقط**: يُرفَع المقطع إلى دلو S3 لتتمكن خوادم Buffer من جلبه من **عنوان عام**. إذا كنت تصيّر محلياً فقط (دون نشر)، فلست بحاجة إلى **أي تخزين على الإطلاق**.

إعدادات `MINIO_*` هي مجرد بيانات اعتماد **S3 قياسية** — أي مزوّد متوافق مع S3 يعمل، وليس MinIO فقط:

| المزوّد | تثبيت؟ | ملاحظات |
|---|---|---|
| **Cloudflare R2** | ❌ | طبقة مجانية + دلاء عامة — الأسهل |
| **AWS S3 / Backblaze B2 / Wasabi / DO Spaces** | ❌ | دلو سحابي + مفاتيح وصول |
| **MinIO ذاتي الاستضافة** | ✅ | يستحق العناء فقط على خادم بنطاق عام |

⚠️ **تنبيه محلي:** يجلب Buffer عبر الإنترنت العام، لذا يجب أن يكون `MINIO_PUBLIC_URL` الخاص بالدلو قابلاً للوصول من خارج جهازك. لن يعمل MinIO على `localhost`/شبكتك المحلية (لا يستطيع Buffer الوصول إليه) — استخدم دلواً سحابياً، أو استضِف MinIO خلف نطاق عام (مثلاً على الجهاز نفسه الذي تستضيف عليه لوحتك). ينشئ التطبيق الدلو تلقائياً ويضبط سياسة قراءة عامة عند أول نشر، ويشذّب الكائنات القديمة بعد `MINIO_RETENTION_HOURS`.

## 🐳 النشر (مجدوِل دائم التشغيل + لوحة تحكم)

أمر واحد — الاستمرارية مضمّنة، لا شيء للإعداد:

```bash
cp .env.example .env      # fill in your keys (optional — you can also do it in the panel)
docker compose up -d      # scheduler + control panel, on http://localhost:1998
```

هذا كل شيء. عند أول إقلاع، **ينشئ التطبيق مخزن إعداداته الخاص** في `data/store.json`
(مبذوراً من `.env` الخاص بك) — لا تنشئ أو "تربط" أي شيء أبداً. ملف
`docker-compose.yml` المرفق يركّب وحدة تخزين مسمّاة عند `/app/data`، فتستمر إعداداتك وكلمة مرور
اللوحة وقائمة الانتظار والسجل **عبر عمليات إعادة التشغيل وإعادة البناء** تلقائياً.

`serve` (الأمر الافتراضي) يبدأ:
- **لوحة تحكم** عند `/` — محمية بكلمة مرور؛ أدِر الإعدادات، وولّد/عاين
  مقطعاً، وانشر الآن، وتصفّح السجل/التحليلات، وجدوِل المقاطع. غيّر أي شيء مباشرةً،
  دون إعادة نشر.
- **مجدوِل داخلي** يصيّر + ينشر عند كل `PUBLISH_TIMES` ضمن `TZ` الخاص بك؛
- `GET /health` و`GET /trigger?key=<TRIGGER_TOKEN>` المؤمَّن برمز للبرمجة النصية.

**وضع بلا واجهة:** شغّل `tabligh serve --no-panel` (أو اضبط `PANEL_ENABLED=false`) لإبقاء
المجدوِل ينشر مع عدم كشف **أي سطح HTTP على الإطلاق** — مثالي إن كنت تدير التطبيق
من الطرفية فقط (قائمة `tabligh`) ولا تريد لوحة ويب لتأمينها.

**يعيش الإعداد في المخزن بعد أول إقلاع** (لتتمكن اللوحة من تحريره مباشرةً). و`.env` فقط
*يبذره* مرة واحدة — لتغيير الأشياء لاحقاً، استخدم اللوحة (أو `tabligh set-password` لإعادة تعيين
كلمة المرور). احذف `data/store.json` لإعادة البذر من `.env`.

**على Coolify / Railway / Fly:** وجّهه إلى هذا المستودع. إن نشرت **`docker-compose.yml`**،
تُنشأ وحدة التخزين لك — بلا خطوات يدوية. إن استخدمت **Dockerfile** المجرد، فإن
سطر `VOLUME /app/data` يجعل معظم المنصات تستمر بها تلقائياً؛ وعلى Coolify يمكنك أيضاً
إضافة وحدة تخزين دائمة واحدة مركّبة عند `/app/data`. اضبط متغيرات البيئة وانشر.

أول تشغيل دون واجهة سطر أوامر؟ فقط افتح اللوحة — تعرض **شاشة إعداد** لإنشاء
كلمة مرورك. تفضّل الطرفية؟ شغّل **`tabligh init`** لمعالج تفاعلي.
