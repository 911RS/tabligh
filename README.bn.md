# 🕌 Tabligh

### بَلِّغُوا عَنِّي وَلَوْ آيَةً
_"আমার পক্ষ থেকে পৌঁছে দাও, একটি আয়াত হলেও।"_ — নবী মুহাম্মদ ﷺ (বুখারি)

**স্বয়ংক্রিয়ভাবে সিনেম্যাটিক, ক্যারাওকে-সিঙ্ক করা কুরআন রিল তৈরি করুন এবং সেগুলো TikTok, Instagram, Facebook ও YouTube-এ প্রকাশ করুন — নির্ধারিত সময়সূচি অনুযায়ী, বিনা হাতে।**

কিছুই বেছে নিতে হবে না। একটি শিডিউলার একটি এলোমেলো সূরা + অংশ নির্বাচন করে, ঠিক সেই তিলাওয়াতটি টেনে আনে, একটি শান্ত পটভূমির উপর শব্দে-শব্দে হাইলাইট সহ একটি উল্লম্ব ভিডিও রেন্ডার করে, এবং দিনে কয়েকবার তা পোস্ট করে।

## ✨ বৈশিষ্ট্য

- 🎬 **সিনেম্যাটিক 1080×1920 রিল** — একটি শক্তিশালী পাঠযোগ্যতা ওভারলে, সূক্ষ্ম ভাসমান কণা, এবং একটি ধীর Ken-Burns ড্রিফট সহ পূর্ণ-প্রস্থ স্টক ফটো পটভূমি (Pexels/Unsplash)।
- 🎨 **তিনটি ভিজ্যুয়াল টেমপ্লেট** — **classic** (ছবি + স্ক্রিম), **glass** (একটি স্থায়ী ফ্রস্টেড গ্লাসমরফিজম কার্ড, একটি লাইভ অডিও ওয়েভফর্ম সহ), এবং **noor** (উষ্ণ "ঐশী আলো" — সোনালি হ্যালো + সোনালি সংখ্যা)। `TEMPLATE` সেট করুন অথবা প্যানেল/মেনুতে এটি পরিবর্তন করুন।
- 🕋 **বিসমিল্লাহ ইন্ট্রো** — যে অংশটি আয়াত ১ থেকে শুরু হয় তা সবসময় ক্বারীর নিজস্ব বিসমিল্লাহ দিয়ে খোলে (তিলাওয়াতকৃত, তার নিজের কণ্ঠে); ঐচ্ছিকভাবে এটি *প্রতিটি* অংশের আগে যোগ করুন (`BASMALA=always`)। আত-তাওবা ও আল-ফাতিহা সঠিকভাবে পরিচালনা করা হয়।
- 🎤 **ক্যারাওকে শব্দ-পূরণ** — প্রতিটি শব্দ তিলাওয়াতের সাথে সিঙ্ক করে উজ্জ্বল হয় (ডান→বাম), যাতে দর্শকরা সাথে সাথে অনুসরণ করতে পারেন।
- 🖋️ **প্রামাণিক আরবি টাইপোগ্রাফি** — পরিচ্ছন্ন আধুনিক **Mada** ফন্টে সঠিক *শাকল* সহ সম্পূর্ণ উসমানি টেক্সট; শিরোনামগুলো **Aref Ruqaa** ক্যালিগ্রাফিতে।
- 🎯 **সঠিক সিঙ্ক, শূন্য AI** — অডিও [everyayah.com](https://everyayah.com) থেকে প্রতি-আয়াত ফাইল হিসেবে আসে, তাই প্রতিটি আয়াতের সময়কাল সঠিক এবং বিনামূল্যে (কোনো ট্রান্সক্রিপশন নেই)।
- 🔀 **স্বয়ংক্রিয় বিষয়বস্তু নির্বাচন** — এলোমেলো সূরা + একটি এলোমেলো ধারাবাহিক অংশ (দৈর্ঘ্য কনফিগারযোগ্য); ছোট সূরাগুলো সম্পূর্ণভাবে রেন্ডার হয়।
- 🌇 **নিরাপদ, রুচিসম্মত পটভূমি** — একটি সুনির্বাচিত ৫০-কীওয়ার্ড পুল (মসজিদ, প্রকৃতি, সমুদ্র, আকাশ…) এবং একটি ফিল্টার যা মানুষ বা অনুপযুক্ত কিছু থাকা যেকোনো ছবি বাদ দেয়। আপনার উৎস বেছে নিন: **Pexels, Unsplash, অথবা আপনার নিজস্ব স্থানীয় ইমেজ ফোল্ডার**।
- 🖥️ **ইন্টারঅ্যাক্টিভ কমান্ড সেন্টার** — রিল তৈরি করতে, প্যানেল চালু/বন্ধ করতে, সারি পরিচালনা করতে, ইতিহাস ব্রাউজ করতে, সেটিংস সম্পাদনা করতে, এবং একটি হেলথ চেক চালাতে একটি চমৎকার টার্মিনাল UI-এর জন্য `tabligh` (কোনো আর্গুমেন্ট ছাড়া) চালান। EN/AR/FR-তে স্থানীয়করণকৃত।
- 🎞️ **স্বাক্ষর আউট্রো** — অংশটি ম্লান হয়ে যায় এবং একটি ছালাওয়াত (আপনার লোগো সহ) একই দৃশ্যের উপর দিয়ে উপরে গ্লাইড করে, তারপর পুরো ভিডিওটি কালো হয়ে ম্লান হয়ে যায়।
- 📤 **মাল্টি-প্ল্যাটফর্ম প্রকাশনা** — [Buffer](https://buffer.com)-এর মাধ্যমে TikTok, Instagram Reels, Facebook Reels ও YouTube Shorts, প্রতি প্ল্যাটফর্ম env দিয়ে টগল করা হয়।
- 🎛️ **সেলফ-হোস্টেড কন্ট্রোল প্যানেল** — প্রতিটি সেটিং পরিচালনা করতে, একটি রিল তৈরি/প্রিভিউ/পোস্ট করতে, অংশ সারিবদ্ধ করতে, এবং ইতিহাস + অ্যানালিটিক্স ব্রাউজ করতে একটি পাসওয়ার্ড-সুরক্ষিত ওয়েব UI — সবই লাইভ, কোনো পুনরায় ডিপ্লয় ছাড়াই। স্থানীয়করণকৃত (EN/AR/FR, সম্পূর্ণ RTL)।
- ⏰ **সেট-অ্যান্ড-ফরগেট শিডিউলার** — একটি সর্বদা-চালু প্রক্রিয়া আপনার টাইমজোনে দিনে N বার পোস্ট করে।
- 🧹 **ডিস্ক-বান্ধব** — পোস্ট করার সাথে সাথেই স্থানীয় ফাইল মুছে ফেলা হয়; ক্লাউড অবজেক্ট স্বয়ংক্রিয়ভাবে ছাঁটা হয়।
- 🐳 **এক-কন্টেইনার ডিপ্লয়** — Dockerfile + Coolify, Fly, Railway, বা যেকোনো Docker হোস্টে দারুণ কাজ করে।

## 🧠 এটি কীভাবে কাজ করে

```
config / random pick
        │
        ▼
Quran text + translation  ──►  everyayah per-ayah audio (exact timing)
   (alquran.cloud)                       │
        │                                ▼
        └────────────►  TimedAyah[]  ──►  background (Pexels/Unsplash, person-filtered)
                                          │
                                          ▼
              Chromium renders animated frames (karaoke, particles, outro)
                                          │
                                          ▼
                    ffmpeg → MP4 (1080×1920) + recitation + silent outro
                                          │
                                          ▼
              object storage (public URL)  ──►  Buffer  ──►  TikTok / IG / FB / YT
                                          │
                                          ▼
                              cleanup (local now, cloud after ingest)
```

## 🚀 দ্রুত শুরু (স্থানীয়)

প্রয়োজনীয়তা: আপনার PATH-এ **Node ≥ 20** এবং **ffmpeg**। (Chromium স্বয়ংক্রিয়ভাবে Puppeteer দ্বারা ডাউনলোড হয়।)

```bash
git clone https://github.com/911RS/tabligh.git
cd tabligh
npm install
cp .env.example .env        # fill in what you need (see below)

# Render a specific passage to work/…/reel.mp4 (no publishing)
npm start render -- --surah 112 --from 1 --to 4 --reciter husary --translation en.sahih

# Render a random passage
npm start random

# Everything the CLI can do
npm start
```

সম্পূর্ণ `reel.mp4` (এবং সময়কাল-সহ `ir.json`) `work/<surah>_<range>_<reciter>__<tag>/`-এ পৌঁছায়।

## ⚙️ কনফিগারেশন

সবকিছু পরিবেশ ভেরিয়েবল (`.env`) দ্বারা চালিত হয়। যেখানে একটি বৈশিষ্ট্যের জন্য একটি কী প্রয়োজন সেই ক্ষেত্র ছাড়া সবগুলোই ঐচ্ছিক।

| ভেরিয়েবল | উদ্দেশ্য | ডিফল্ট |
|---|---|---|
| `TEMPLATE` | রিলের ভিজ্যুয়াল স্টাইল: `classic` / `glass` / `noor` | `classic` |
| `BASMALA` | বিসমিল্লাহ ইন্ট্রো: `off` (শুধু আয়াত ১-এ) / `always` (প্রতিটি অংশে) | `off` |
| `BACKGROUND_SOURCE` | `auto` / `pexels` / `unsplash` / `local` | `auto` |
| `BACKGROUND_LOCAL_DIR` | আপনার নিজস্ব পোর্ট্রেট ছবির ফোল্ডার (যখন source = `local`) | _(খালি)_ |
| `PEXELS_API_KEY` / `UNSPLASH_ACCESS_KEY` | স্টক ফটো পটভূমি | _(সেট না → গ্র্যাডিয়েন্ট ফলব্যাক)_ |
| `BUFFER_ACCESS_TOKEN` | প্রকাশনার জন্য Buffer API টোকেন | _(সেট না → কোনো প্রকাশনা নেই)_ |
| `BUFFER_TIKTOK_CHANNEL_IDS` | কমা-বিভক্ত TikTok চ্যানেল আইডি | _(খালি)_ |
| `BUFFER_INSTAGRAM_CHANNEL_IDS` | Instagram Reels চ্যানেল আইডি | _(খালি)_ |
| `BUFFER_FACEBOOK_CHANNEL_IDS` | Facebook Reels চ্যানেল আইডি | _(খালি)_ |
| `BUFFER_YOUTUBE_CHANNEL_IDS` | YouTube Shorts চ্যানেল আইডি | _(খালি)_ |
| `MINIO_*` | S3-সামঞ্জস্যপূর্ণ স্টোরেজ (পাবলিক বাকেট যা থেকে Buffer আনে) | বাকেট `tabligh`, পোর্ট `9000` |
| `TZ` / `PUBLISH_TIMES` | টাইমজোন + দিনের যে সময়ে স্বয়ংক্রিয়-পোস্ট হবে | `Africa/Tunis` / `07:00,13:00,19:00` |
| `KARAOKE_ENABLED` | তিলাওয়াতের সাথে সিঙ্ক করা শব্দে-শব্দে পূরণ | `true` |
| `TEXT_FILL_COLOR` | তিলাওয়াতকৃত (পূরণকৃত) টেক্সটের রঙ | `#ffffff` |
| `WATERMARK_ENABLED` / `WATERMARK_HANDLE` | কোণার লোগো ওয়াটারমার্ক (`assets/logo.png`) | `true` / _(খালি)_ |
| `FULL_SURAH_MAX_AYAHS` | এত ছোট সূরাগুলো সম্পূর্ণভাবে রেন্ডার হয় | `7` |
| `RANDOM_MIN_AYAHS` / `RANDOM_MAX_AYAHS` | এলোমেলো মোডের জন্য অংশের দৈর্ঘ্য | `5` / `10` |
| `MAX_VIDEO_SECONDS` | তিলাওয়াতের দৈর্ঘ্য সীমাবদ্ধ করুন (আউট্রো বাদে); মানানসই করতে শেষের আয়াতগুলো ছাঁটে (min-কে অগ্রাহ্য করে) | `0` _(কোনো সীমা নেই)_ |
| `RETENTION_DAYS` / `MINIO_RETENTION_HOURS` | পরিষ্কারের সময়সীমা | `7` দিন / `24` ঘণ্টা |
| `PORT` / `TRIGGER_TOKEN` | HTTP সার্ভার + ট্রিগার এন্ডপয়েন্টের জন্য গোপন কী | `1998` / _(সেট না → নিষ্ক্রিয়)_ |
| `PANEL_ENABLED` | কন্ট্রোল প্যানেল সার্ভ করুন (`false` = হেডলেস, শুধু শিডিউলার) | `true` |
| `UI_LANG` | ইন্টারঅ্যাক্টিভ টার্মিনাল-মেনুর ভাষা (`en` / `ar` / `fr`) | `en` |

সম্পূর্ণ টীকা-সহ তালিকার জন্য [`.env.example`](.env.example) দেখুন। **এই মানগুলো শুধুমাত্র প্রথম রানে স্টোরে বীজ বপন করে** — তার পরে, প্যানেলে বা `tabligh` মেনুতে সেটিংস লাইভ পরিচালনা করুন।

**ক্বারীগণ:** `husary`, `minshawy`, `abdulbasit`, `hudhaify`, `ayyoub`, `shuraym`, `husary-muallim`, `tunaiji` — অথবা যেকোনো কাঁচা [everyayah](https://everyayah.com) ফোল্ডার। দেখুন [`src/quran/reciters.ts`](src/quran/reciters.ts)।

**অনুবাদ:** যেকোনো [alquran.cloud](https://alquran.cloud) সংস্করণ আইডি, যেমন `en.sahih`, `fr.hamidullah`, অথবা শুধু আরবির জন্য `""`।

- **একটি রিল তৈরি করুন** — এলোমেলো বা একটি অংশ বেছে নিন; স্থানীয়ভাবে রেন্ডার করে (লাইভ অগ্রগতি সহ), তারপর ভিডিওটি খোলার বা প্রকাশ করার প্রস্তাব দেয়।
- **এখনই প্রকাশ করুন** — এক ধাপে তৈরি + প্রকাশ।
- **কন্ট্রোল প্যানেল** — একটি ব্যাকগ্রাউন্ড সার্ভিস হিসেবে ওয়েব প্যানেল **চালু / বন্ধ / পুনরায় চালু** করুন, আপনার ব্রাউজারে এটি **খুলুন**, অথবা **এর লগ টেইল করুন** — দেখাশোনার জন্য কোনো আলাদা প্রক্রিয়া নেই।
- **সারি** — শিডিউলার এলোমেলো নির্বাচনের আগে যে অংশগুলো চালায় তা যোগ/অপসারণ করুন।
- **ইতিহাস ও অ্যানালিটিক্স** — মোট সংখ্যা, প্ল্যাটফর্ম অনুযায়ী বিভাজন, সাম্প্রতিক পোস্ট।
- **সেটিংস** — ভাষা, পটভূমি উৎস (স্থানীয় ফোল্ডার সহ), শিডিউলার চালু/বন্ধ, শিডিউল, বিষয়বস্তু, চ্যানেল, এবং API কী — সবই লাইভ প্রয়োগ করা হয়।
- **ডাক্তার** — এক নজরে হেলথ চেক (ffmpeg, Chrome, কী, স্টোরেজ, ডিস্ক)।

**English / العربية / Français**-এ স্থানীয়করণকৃত (`UI_LANG` সেট করুন অথবা সেটিংসে এটি পরিবর্তন করুন)। নন-ইন্টারঅ্যাক্টিভ প্রসঙ্গে (পাইপ, Docker, CI) পরিবর্তে ক্লাসিক সাহায্য প্রিন্ট হয়, তাই স্ক্রিপ্টিং অপ্রভাবিত থাকে। এছাড়াও রয়েছে `tabligh menu` (এটি বাধ্য করুন) এবং `tabligh doctor` (শুধু হেলথ চেক চালান)।

## 🎛️ ওয়েব কন্ট্রোল প্যানেল ও CLI

একটি পাসওয়ার্ড-সুরক্ষিত প্যানেলের জন্য অ্যাপ রুট (`http://localhost:1998`) খুলুন:

- **প্রথম রান** আপনার পাসওয়ার্ড তৈরি করতে একটি সেটআপ স্ক্রিন দেখায় (অথবা একটি টার্মিনাল উইজার্ডের জন্য `tabligh init` চালান — এটি এখন আপনার ড্যাশবোর্ড URL দেখিয়ে এবং প্যানেল চালু করার প্রস্তাব দিয়ে শেষ হয়)।
- **ড্যাশবোর্ড** — স্ট্যাটাস, এক-ক্লিকে *এখনই তৈরি করুন* / *+ প্রকাশ করুন*, সর্বশেষ প্রিভিউ।
- **তৈরি করুন** — একটি অংশ বেছে নিন বা এলোমেলো যান, পোস্ট করার আগে প্রিভিউ দেখুন।
- **সেটিংস** — শিডিউল (টাইমজোন + সময় নির্বাচক), বিষয়বস্তু (অনুবাদ, আয়াত সংখ্যা, **সর্বোচ্চ দৈর্ঘ্য**), ব্র্যান্ডিং (ক্যারাওকে, পূরণ রঙ, কণা, অ্যানিমেটেড পটভূমি, আউট্রো প্রোমো), প্ল্যাটফর্ম চ্যানেল আইডি, API কী ও স্টোরেজ — **লাইভ** প্রয়োগ করা হয়।
- **সারি** — নির্দিষ্ট অংশ পরিকল্পনা করুন; শিডিউলার এলোমেলো নির্বাচনের আগে সেগুলো চালায়।
- **ইতিহাস / অ্যানালিটিক্স** — প্রতিটি রেন্ডার + পোস্ট, মোট সংখ্যা, প্ল্যাটফর্ম অনুযায়ী, সাম্প্রতিক লগ।
- **ভাষা** — প্যানেলটি English, العربية (RTL) ও Français-এর মধ্যে পরিবর্তন করুন।

লগইন রেট-সীমিত (৫ বার চেষ্টা → ১৫-মিনিট লকআউট)। সার্ভার থেকে পাসওয়ার্ড রিসেট করুন
`tabligh set-password <new>` দিয়ে (যেমন `docker exec <container> tabligh set-password …`)।

সেটিংস স্টোরে থাকে এবং `/app/data` ভলিউমে টিকে থাকে; `.env` শুধুমাত্র প্রথম রানে সেগুলো বীজ বপন করে।

### 🌐 প্যানেল অ্যাক্সেস করা

অ্যাপটির নিজস্ব কোনো ডোমেইন নেই — এটি সব ইন্টারফেসে শুধু একটি পোর্টে (ডিফল্টভাবে **`1998`**, `PORT` দিয়ে ওভাররাইড করুন) শোনে। আপনি কোন URL খোলেন তা নির্ভর করে এটি কোথায় চলছে তার উপর:

| যেখানে এটি চলে | যে URL আপনি খোলেন | HTTPS? |
|---|---|---|
| আপনার নিজের কম্পিউটার (`npm` / স্থানীয়) | `http://localhost:1998` | — (স্থানীয়, ঠিক আছে) |
| ক্লাউড VPS, কাঁচা পোর্ট উন্মুক্ত | `http://<your-server-ip>:1998` | ❌ **না** |
| রিভার্স প্রক্সির পিছনে VPS | `https://yourdomain.com` | ✅ প্রক্সি এটি সরবরাহ করে |

- **স্থানীয়ভাবে**, সেটআপ উইজার্ড চালু হওয়ার সময় সঠিক লিঙ্কটি প্রিন্ট করে (`http://localhost:1998`)।
- **একটি VPS-এ**, `http://<server-ip>:1998`-এ পৌঁছাতে আপনার ফায়ারওয়াল / সিকিউরিটি গ্রুপকে ইনবাউন্ড `1998` অনুমোদন করাও প্রয়োজন।
- **⚠️ কাঁচা পোর্টটি ইন্টারনেটে উন্মুক্ত রেখে দেবেন না।** প্যানেলটি প্লেইন HTTP সার্ভ করে, তাই আপনার লগইন পাসওয়ার্ড এনক্রিপ্ট না হয়ে ভ্রমণ করবে। এটি একটি রিভার্স প্রক্সির পিছনে রাখুন যা TLS টার্মিনেট করে:
  - **[Coolify](https://coolify.io)** (প্রস্তাবিত) — অ্যাপে একটি ডোমেইন সেট করুন এবং এটিকে পোর্ট `1998`-এ নির্দেশ করুন; Coolify-এর Traefik রাউটিং **এবং** একটি Let's Encrypt সার্টিফিকেট স্বয়ংক্রিয়ভাবে পরিচালনা করে।
  - **Nginx / Caddy** — আপনার ডোমেইন + সার্টের পিছনে `proxy_pass http://127.0.0.1:1998`।

অ্যাপটির কখনো তার পাবলিক ডোমেইন জানার প্রয়োজন নেই; প্রক্সি ডোমেইন ও HTTPS-এর মালিক এবং অভ্যন্তরীণভাবে `1998`-এ ফরওয়ার্ড করে।

## 📤 প্রকাশনা

প্রকাশনা [Buffer](https://buffer.com)-এর মাধ্যমে হয়, যা প্রতিটি সংযুক্ত প্ল্যাটফর্মে ছড়িয়ে দেয়।

1. একটি Buffer অ্যাকাউন্ট তৈরি করুন এবং আপনার TikTok / Instagram / Facebook / YouTube চ্যানেল সংযুক্ত করুন।
2. `BUFFER_ACCESS_TOKEN` সেট করুন, তারপর আপনার চ্যানেল আইডি তালিকাভুক্ত করতে `npm start channels` চালান।
3. আইডিগুলো সংশ্লিষ্ট `BUFFER_*_CHANNEL_IDS` ভেরিয়েবলে রাখুন (যেকোনো উপসেট — শুধু TikTok ঠিক আছে)।
4. `npm start random -- --publish` (অথবা শিডিউলারকে এটি করতে দিন)।

প্রতিটি প্ল্যাটফর্ম স্বয়ংক্রিয়ভাবে সঠিক ফরম্যাট পায় (Reel / Short)। ক্যাপশনে সূরা, আয়াত পরিসর, ক্বারী, ফটো ক্রেডিট, এবং হ্যাশট্যাগ অন্তর্ভুক্ত থাকে।

### স্টোরেজ — আপনাকে MinIO ইনস্টল করতে হবে না

অবজেক্ট স্টোরেজ **শুধুমাত্র প্রকাশনার জন্য** ব্যবহৃত হয়: রিলটি একটি S3 বাকেটে আপলোড করা হয় যাতে Buffer-এর সার্ভার এটি একটি **পাবলিক URL** থেকে আনতে পারে। আপনি যদি শুধু স্থানীয়ভাবে রেন্ডার করেন (কোনো প্রকাশনা নেই), তাহলে আপনার **কোনো স্টোরেজেরই** প্রয়োজন নেই।

`MINIO_*` সেটিংস শুধুই **স্ট্যান্ডার্ড S3** শংসাপত্র — যেকোনো S3-সামঞ্জস্যপূর্ণ প্রোভাইডার কাজ করে, শুধু MinIO নয়:

| প্রোভাইডার | ইনস্টল? | নোট |
|---|---|---|
| **Cloudflare R2** | ❌ | ফ্রি টিয়ার + পাবলিক বাকেট — সবচেয়ে সহজ |
| **AWS S3 / Backblaze B2 / Wasabi / DO Spaces** | ❌ | ক্লাউড বাকেট + অ্যাক্সেস কী |
| **সেলফ-হোস্টেড MinIO** | ✅ | শুধু একটি পাবলিক ডোমেইন সহ সার্ভারে এটি মূল্যবান |

⚠️ **স্থানীয় সতর্কতা:** Buffer পাবলিক ইন্টারনেটের মাধ্যমে আনে, তাই বাকেটের `MINIO_PUBLIC_URL` আপনার মেশিনের বাইরে থেকে পৌঁছানো যেতে হবে। `localhost`/আপনার LAN-এ একটি MinIO **কাজ করবে না** (Buffer এটিতে পৌঁছাতে পারে না) — একটি ক্লাউড বাকেট ব্যবহার করুন, অথবা একটি পাবলিক ডোমেইনের পিছনে MinIO হোস্ট করুন (যেমন আপনার প্যানেলের একই বক্সে)। অ্যাপটি স্বয়ংক্রিয়ভাবে বাকেট তৈরি করে এবং প্রথম প্রকাশনায় একটি পাবলিক-রিড পলিসি সেট করে, এবং `MINIO_RETENTION_HOURS`-এর পরে পুরানো অবজেক্ট ছাঁটে।

## 🐳 ডিপ্লয়মেন্ট (সর্বদা-চালু শিডিউলার + কন্ট্রোল প্যানেল)

একটি কমান্ড — পার্সিস্টেন্স অন্তর্ভুক্ত, সেটআপ করার কিছু নেই:

```bash
cp .env.example .env      # fill in your keys (optional — you can also do it in the panel)
docker compose up -d      # scheduler + control panel, on http://localhost:1998
```

এটুকুই। প্রথম বুটে অ্যাপটি `data/store.json`-এ **তার নিজস্ব কনফিগ স্টোর তৈরি করে**
(আপনার `.env` থেকে বীজ বপন করে) — আপনি কখনো কিছু তৈরি বা "লিঙ্ক" করেন না। বান্ডেলকৃত
`docker-compose.yml` `/app/data`-তে একটি নামযুক্ত ভলিউম মাউন্ট করে, তাই আপনার সেটিংস, প্যানেল
পাসওয়ার্ড, সারি ও ইতিহাস স্বয়ংক্রিয়ভাবে **পুনরায় চালু ও পুনর্নির্মাণ জুড়ে টিকে থাকে**।

`serve` (ডিফল্ট কমান্ড) চালু করে:
- `/`-তে একটি **কন্ট্রোল প্যানেল** — পাসওয়ার্ড-সুরক্ষিত; সেটিংস পরিচালনা করুন, একটি রিল
  তৈরি/প্রিভিউ করুন, এখনই পোস্ট করুন, ইতিহাস/অ্যানালিটিক্স ব্রাউজ করুন, এবং অংশ সারিবদ্ধ করুন। যেকোনো কিছু লাইভ পরিবর্তন করুন,
  কোনো পুনরায় ডিপ্লয় ছাড়াই।
- একটি **অভ্যন্তরীণ শিডিউলার** যা আপনার `TZ`-তে প্রতিটি `PUBLISH_TIMES`-এ রেন্ডার + প্রকাশ করে;
- স্ক্রিপ্টিংয়ের জন্য `GET /health` এবং একটি টোকেন-সুরক্ষিত `GET /trigger?key=<TRIGGER_TOKEN>`।

**হেডলেস মোড:** **কোনো HTTP পৃষ্ঠতল একেবারেই** উন্মুক্ত না করে শিডিউলারকে পোস্ট করা চালিয়ে যেতে
`tabligh serve --no-panel` চালান (অথবা `PANEL_ENABLED=false` সেট করুন) — আদর্শ যদি আপনি অ্যাপটি শুধু
টার্মিনাল থেকে (`tabligh` মেনু) পরিচালনা করেন এবং সুরক্ষিত করার জন্য একটি ওয়েব প্যানেল না চান।

**প্রথম বুটের পরে কনফিগ স্টোরে থাকে** (যাতে প্যানেল এটি লাইভ সম্পাদনা করতে পারে)। `.env` শুধুমাত্র
একবার এটিতে *বীজ বপন* করে — পরে জিনিস পরিবর্তন করতে, প্যানেল ব্যবহার করুন (অথবা পাসওয়ার্ড রিসেট করতে
`tabligh set-password`)। `.env` থেকে পুনরায় বীজ বপন করতে `data/store.json` মুছুন।

**Coolify / Railway / Fly-তে:** এটিকে এই রিপোতে নির্দেশ করুন। আপনি যদি **`docker-compose.yml`** ডিপ্লয় করেন,
ভলিউম আপনার জন্য তৈরি হয় — শূন্য ম্যানুয়াল ধাপ। আপনি যদি সাধারণ **Dockerfile** ব্যবহার করেন, তাহলে
`VOLUME /app/data` লাইনটি বেশিরভাগ প্ল্যাটফর্মকে এটি স্বয়ংক্রিয়ভাবে টিকিয়ে রাখতে সাহায্য করে; Coolify-তে আপনি
`/app/data`-তে মাউন্ট করা একটি Persistent Storage-ও যোগ করতে পারেন। আপনার env ভেরিয়েবল সেট করুন এবং ডিপ্লয় করুন।

CLI ছাড়া প্রথম রান? শুধু প্যানেলটি খুলুন — এটি আপনার পাসওয়ার্ড তৈরি করতে একটি **সেটআপ স্ক্রিন** দেখায়।
টার্মিনাল পছন্দ করেন? একটি ইন্টারঅ্যাক্টিভ উইজার্ডের জন্য **`tabligh init`** চালান।
