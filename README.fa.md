## ✨ ویژگی‌ها

- 🎬 **ریلز‌های سینمایی ۱۰۸۰×۱۹۲۰** — پس‌زمینهٔ عکس استوک تمام‌قاب (Pexels/Unsplash) با یک لایهٔ خوانایی قدرتمند، ذرات ظریف شناور و یک حرکت آهستهٔ کن-برنز.
- 🎨 **سه قالب بصری** — **classic** (عکس + لایهٔ تیره)، **glass** (یک کارت گلس‌مورفیسم مات و ماندگار همراه با شکل موج صوتی زنده)، و **noor** (نور الهی گرم — هالهٔ طلایی + اعداد زرنگار). `TEMPLATE` را تنظیم کنید یا آن را در پنل/منو جابه‌جا کنید.
- 🕋 **مقدمهٔ بسم‌الله** — بخشی که از آیهٔ ۱ آغاز می‌شود همیشه با بسملهٔ خودِ قاری (تلاوت‌شده، با صدای خودش) باز می‌شود؛ به‌دلخواه می‌توانید آن را پیش از *هر* بخش قرار دهید (`BASMALA=always`). سوره‌های توبه و فاتحه به‌درستی مدیریت می‌شوند.
- 🎤 **پُرشدن کلمه‌ای کاراوکه** — هر کلمه هماهنگ با تلاوت روشن می‌شود (راست←چپ)، تا بینندگان همراهی کنند.
- 🖋️ **حروف‌نگاری اصیل عربی** — متن کامل عثمانی با *شکل* صحیح در چهرهٔ مدرن و پاکیزهٔ **Mada**؛ سرتیترها با خوشنویسی **Aref Ruqaa**.
- 🎯 **همگام‌سازی دقیق، بدون هوش مصنوعی** — صدا از [everyayah.com](https://everyayah.com) به‌صورت فایل‌های جداگانه برای هر آیه می‌آید، بنابراین زمان‌بندی هر آیه دقیق و رایگان است (بدون رونویسی).
- 🔀 **انتخاب خودکار محتوا** — سورهٔ تصادفی + یک بخش پیوستهٔ تصادفی (با طول قابل‌تنظیم)؛ سوره‌های کوتاه به‌طور کامل رندر می‌شوند.
- 🌇 **پس‌زمینه‌های امن و باسلیقه** — یک مجموعهٔ گزیده از ۵۰ کلیدواژه (مساجد، طبیعت، دریا، آسمان…) به‌همراه فیلتری که هر عکس شامل انسان یا هر چیز نامناسب را حذف می‌کند. منبع خود را انتخاب کنید: **Pexels، Unsplash، یا پوشهٔ تصاویر محلی خودتان**.
- 🖥️ **مرکز فرمان تعاملی** — `tabligh` (بدون آرگومان) را اجرا کنید تا یک رابط کاربری خیره‌کنندهٔ ترمینال برای ساخت ریلز، شروع/توقف پنل، مدیریت صف، مرور تاریخچه، ویرایش تنظیمات و اجرای بررسی سلامت داشته باشید. بومی‌سازی‌شده به EN/AR/FR.
- 🎞️ **اوترو امضایی** — بخش محو می‌شود و یک صلوات (همراه با لوگوی شما) روی همان صحنه به‌بالا می‌لغزد، سپس کل ویدیو به سیاهی محو می‌گردد.
- 📤 **انتشار چندسکویی** — تیک‌تاک، ریلز اینستاگرام، ریلز فیس‌بوک و شورتس یوتیوب از طریق [Buffer](https://buffer.com)، که برای هر سکو با متغیر محیطی روشن/خاموش می‌شود.
- 🎛️ **پنل کنترل خودمیزبان** — یک رابط کاربری وب محافظت‌شده با رمز عبور برای مدیریت هر تنظیم، ساخت/پیش‌نمایش/انتشار یک ریلز، صف‌بندی بخش‌ها، و مرور تاریخچه + تحلیل‌ها — همه به‌صورت زنده، بدون استقرار مجدد. بومی‌سازی‌شده (EN/AR/FR، با پشتیبانی کامل RTL).
- ⏰ **زمان‌بند تنظیم‌کن-و-فراموش‌کن** — یک فرایند همیشه‌روشن N بار در روز در منطقهٔ زمانی شما منتشر می‌کند.
- 🧹 **صرفه‌جو در فضای دیسک** — فایل‌های محلی بلافاصله پس از انتشار پاک می‌شوند؛ اشیای ابری به‌طور خودکار هرس می‌گردند.
- 🐳 **استقرار تک‌کانتینری** — Dockerfile + روی Coolify، Fly، Railway یا هر میزبان Docker عالی کار می‌کند.

## 🚀 شروع سریع (محلی)

پیش‌نیازها: **Node ≥ 20** و **ffmpeg** روی PATH شما. (Chromium به‌طور خودکار توسط Puppeteer دانلود می‌شود.)

```bash
git clone https://github.com/911RS/tabligh.git
cd tabligh
npm install
cp .env.example .env        # fill in what you need (see below)

# Render a specific passage to work/…/reel.mp4 (no publishing)
npm start render -- --surah 112 --from 1 --to 4 --reciter husary --translation en.sahih

# Render a random passage
npm start random

# Everything the CLI can do
npm start
```

فایل نهایی `reel.mp4` (به‌همراه `ir.json` زمان‌بندی‌شده) در `work/<surah>_<range>_<reciter>__<tag>/` قرار می‌گیرد.

## ⚙️ پیکربندی

همه چیز با متغیرهای محیطی (`.env`) هدایت می‌شود. همه اختیاری هستند مگر جایی که یک ویژگی به یک کلید نیاز دارد.

| متغیر | هدف | پیش‌فرض |
|---|---|---|
| `TEMPLATE` | سبک بصری ریلز: `classic` / `glass` / `noor` | `classic` |
| `BASMALA` | مقدمهٔ بسم‌الله: `off` (فقط در آیهٔ ۱) / `always` (هر بخش) | `off` |
| `BACKGROUND_SOURCE` | `auto` / `pexels` / `unsplash` / `local` | `auto` |
| `BACKGROUND_LOCAL_DIR` | پوشهٔ تصاویر عمودی خودتان (هنگامی که منبع = `local`) | _(خالی)_ |
| `PEXELS_API_KEY` / `UNSPLASH_ACCESS_KEY` | پس‌زمینه‌های عکس استوک | _(تنظیم‌نشده ← بازگشت به گرادیان)_ |
| `BUFFER_ACCESS_TOKEN` | توکن API بافر برای انتشار | _(تنظیم‌نشده ← بدون انتشار)_ |
| `BUFFER_TIKTOK_CHANNEL_IDS` | شناسه‌های کانال تیک‌تاک، جداشده با کاما | _(خالی)_ |
| `BUFFER_INSTAGRAM_CHANNEL_IDS` | شناسه‌های کانال ریلز اینستاگرام | _(خالی)_ |
| `BUFFER_FACEBOOK_CHANNEL_IDS` | شناسه‌های کانال ریلز فیس‌بوک | _(خالی)_ |
| `BUFFER_YOUTUBE_CHANNEL_IDS` | شناسه‌های کانال شورتس یوتیوب | _(خالی)_ |
| `MINIO_*` | ذخیره‌سازی سازگار با S3 (باکت عمومی که بافر از آن دریافت می‌کند) | باکت `tabligh`، پورت `9000` |
| `TZ` / `PUBLISH_TIMES` | منطقهٔ زمانی + ساعت‌های روز برای انتشار خودکار | `Africa/Tunis` / `07:00,13:00,19:00` |
| `KARAOKE_ENABLED` | پُرشدن کلمه‌به‌کلمه همگام با تلاوت | `true` |
| `TEXT_FILL_COLOR` | رنگ متن تلاوت‌شده (پُرشده) | `#ffffff` |
| `WATERMARK_ENABLED` / `WATERMARK_HANDLE` | واترمارک لوگو در گوشه (`assets/logo.png`) | `true` / _(خالی)_ |
| `OUTRO_TEXT` | متن پایانی اوترو | یک صلوات |
| `FULL_SURAH_MAX_AYAHS` | سوره‌هایی که این‌قدر کوتاه‌اند به‌طور کامل رندر می‌شوند | `7` |
| `RANDOM_MIN_AYAHS` / `RANDOM_MAX_AYAHS` | طول بخش برای حالت تصادفی | `5` / `10` |
| `MAX_VIDEO_SECONDS` | سقف طول تلاوت (بدون اوترو)؛ آیه‌های انتهایی را برای جا شدن کوتاه می‌کند (بر حداقل ارجحیت دارد) | `0` _(بدون محدودیت)_ |
| `RETENTION_DAYS` / `MINIO_RETENTION_HOURS` | بازه‌های پاکسازی | `7` روز / `24` ساعت |
| `PORT` / `TRIGGER_TOKEN` | سرور HTTP + رمز مخفی برای نقطهٔ پایانی trigger | `1998` / _(تنظیم‌نشده ← غیرفعال)_ |
| `PANEL_ENABLED` | ارائهٔ پنل کنترل (`false` = بدون رابط، فقط زمان‌بند) | `true` |
| `UI_LANG` | زبان منوی تعاملی ترمینال (`en` / `ar` / `fr`) | `en` |

برای فهرست کامل و حاشیه‌نویسی‌شده به [`.env.example`](.env.example) مراجعه کنید. **این مقادیر فقط در نخستین اجرا مخزن را مقداردهی اولیه می‌کنند** — پس از آن، تنظیمات را به‌صورت زنده در پنل یا منوی `tabligh` مدیریت کنید.

**قاریان:** `husary`، `minshawy`، `abdulbasit`، `hudhaify`، `ayyoub`، `shuraym`، `husary-muallim`، `tunaiji` — یا هر پوشهٔ خام [everyayah](https://everyayah.com). به [`src/quran/reciters.ts`](src/quran/reciters.ts) مراجعه کنید.

**ترجمه‌ها:** هر شناسهٔ نسخهٔ [alquran.cloud](https://alquran.cloud)، مثلاً `en.sahih`، `fr.hamidullah`، یا `""` برای فقط عربی.

## 🖥️ مرکز فرمان تعاملی

**`tabligh`** را بدون آرگومان در یک ترمینال اجرا کنید تا منوی تعاملی باز شود — یک مرکز فرمان مستقل و کامل برای همه چیز:

<div align="center">
  <img src="docs/screenshots/cli-command-center.jpg" width="720" alt="مرکز فرمان تعاملی Tabligh — رابط ترمینالی اصلی-جزئیات با بنر گرادیانی، وضعیت زنده، منو و پنل کاری"/>
</div>

```
tabligh                 # opens the menu (in a TTY)
```

- **ساخت یک ریلز** — تصادفی یا انتخاب یک بخش؛ به‌صورت محلی رندر می‌شود (با پیشرفت زنده)، سپس پیشنهاد باز کردن ویدیو یا انتشار آن را می‌دهد.
- **همین حالا منتشر کن** — ساخت + انتشار در یک گام.
- **پنل کنترل** — پنل وب را به‌عنوان یک سرویس پس‌زمینه **شروع / متوقف / راه‌اندازی مجدد** کنید، آن را در مرورگر خود **باز** کنید، یا **لاگ‌های آن را دنبال** کنید — بدون فرایند جداگانه‌ای که نیاز به مراقبت داشته باشد.
- **صف** — بخش‌هایی را که زمان‌بند پیش از انتخاب‌های تصادفی پخش می‌کند اضافه/حذف کنید.
- **تاریخچه و تحلیل‌ها** — مجموع‌ها، تفکیک بر اساس سکو، پست‌های اخیر.
- **تنظیمات** — زبان، منبع پس‌زمینه (از جمله پوشهٔ محلی)، روشن/خاموش زمان‌بند، زمان‌بندی، محتوا، کانال‌ها و کلیدهای API — همه به‌صورت زنده اعمال می‌شوند.
- **دکتر (Doctor)** — بررسی سلامت در یک نگاه (ffmpeg، Chrome، کلیدها، ذخیره‌سازی، دیسک).

بومی‌سازی‌شده به **English / العربية / Français** (`UI_LANG` را تنظیم کنید یا آن را در تنظیمات جابه‌جا کنید). زمینه‌های غیرتعاملی (pipe‌ها، Docker، CI) به‌جای آن راهنمای کلاسیک را چاپ می‌کنند، بنابراین اسکریپت‌نویسی بی‌تأثیر می‌ماند. همچنین `tabligh menu` (اجبار آن) و `tabligh doctor` (اجرای صرفِ بررسی سلامت) وجود دارد.

## 🎛️ پنل کنترل وب و CLI

ریشهٔ برنامه (`http://localhost:1998`) را برای یک پنل محافظت‌شده با رمز عبور باز کنید:

- **نخستین اجرا** یک صفحهٔ راه‌اندازی برای ساخت رمز عبور شما نشان می‌دهد (یا `tabligh init` را برای یک جادوگر ترمینالی اجرا کنید — اکنون در پایان نشانی داشبورد شما را نمایش می‌دهد و پیشنهاد شروع پنل را می‌کند).
- **داشبورد** — وضعیت، *همین حالا بساز* / *+ انتشار* با یک کلیک، آخرین پیش‌نمایش.
- **ساخت** — یک بخش را انتخاب کنید یا تصادفی بروید، پیش از انتشار پیش‌نمایش کنید.
- **تنظیمات** — زمان‌بندی (منطقهٔ زمانی + انتخابگر زمان)، محتوا (ترجمه، تعداد آیه، **حداکثر طول**)، برندینگ (کاراوکه، رنگ پُرشدن، ذرات، پس‌زمینهٔ متحرک، تبلیغ اوترو)، شناسه‌های کانال سکوها، کلیدهای API و ذخیره‌سازی — به‌صورت **زنده** اعمال می‌شوند.
- **صف** — بخش‌های مشخصی را برنامه‌ریزی کنید؛ زمان‌بند آن‌ها را پیش از انتخاب‌های تصادفی پخش می‌کند.
- **تاریخچه / تحلیل‌ها** — هر رندر + پست، مجموع‌ها، تفکیک بر اساس سکو، لاگ‌های اخیر.
- **زبان** — پنل را میان English، العربية (RTL) و Français جابه‌جا کنید.

ورود دارای محدودیت نرخ است (۵ تلاش ← قفل ۱۵ دقیقه‌ای). رمز عبور را از سرور با
`tabligh set-password <new>` بازنشانی کنید (مثلاً `docker exec <container> tabligh set-password …`).

تنظیمات در مخزن قرار دارند و روی والیوم `/app/data` پایدار می‌مانند؛ `.env` فقط آن‌ها را در نخستین اجرا مقداردهی می‌کند.

### 🌐 دسترسی به پنل

برنامه دامنهٔ اختصاصی خود را ندارد — فقط روی یک پورت (به‌طور پیش‌فرض **`1998`**، با `PORT` بازنویسی می‌شود) روی همهٔ رابط‌ها گوش می‌دهد. اینکه چه نشانی‌ای را باز می‌کنید بستگی به جایی دارد که اجرا می‌شود:

| جایی که اجرا می‌شود | نشانی‌ای که باز می‌کنید | HTTPS؟ |
|---|---|---|
| رایانهٔ خودتان (`npm` / محلی) | `http://localhost:1998` | — (محلی، مشکلی نیست) |
| VPS ابری، پورت خام در معرض | `http://<your-server-ip>:1998` | ❌ **خیر** |
| VPS پشت یک پروکسی معکوس | `https://yourdomain.com` | ✅ پروکسی آن را فراهم می‌کند |

- **به‌صورت محلی**، جادوگر راه‌اندازی نشانی دقیق را هنگام شروع چاپ می‌کند (`http://localhost:1998`).
- **روی یک VPS**، دسترسی به `http://<server-ip>:1998` همچنین نیازمند آن است که فایروال / گروه امنیتی شما ترافیک ورودی `1998` را مجاز کند.
- **⚠️ پورت خام را در معرض اینترنت رها نکنید.** پنل HTTP ساده ارائه می‌کند، بنابراین رمز ورود شما رمزنگاری‌نشده منتقل می‌شود. آن را پشت یک پروکسی معکوس که TLS را خاتمه می‌دهد قرار دهید:
  - **[Coolify](https://coolify.io)** (توصیه‌شده) — یک دامنه روی برنامه تنظیم کنید و آن را به پورت `1998` اشاره دهید؛ Traefik در Coolify مسیریابی **و** یک گواهی Let's Encrypt را به‌طور خودکار مدیریت می‌کند.
  - **Nginx / Caddy** — `proxy_pass http://127.0.0.1:1998` پشت دامنه + گواهی شما.

برنامه هرگز نیازی به دانستن دامنهٔ عمومی خود ندارد؛ پروکسی مالک دامنه و HTTPS است و به‌صورت داخلی به `1998` ارسال می‌کند.

## 📤 انتشار

انتشار از طریق [Buffer](https://buffer.com) انجام می‌شود، که به هر سکوی متصل توزیع می‌کند.

1. یک حساب بافر بسازید و کانال‌های تیک‌تاک / اینستاگرام / فیس‌بوک / یوتیوب خود را متصل کنید.
2. `BUFFER_ACCESS_TOKEN` را تنظیم کنید، سپس `npm start channels` را اجرا کنید تا شناسه‌های کانال خود را فهرست کنید.
3. شناسه‌ها را در متغیرهای متناظر `BUFFER_*_CHANNEL_IDS` قرار دهید (هر زیرمجموعه‌ای — فقط تیک‌تاک هم اشکالی ندارد).
4. `npm start random -- --publish` (یا بگذارید زمان‌بند این کار را انجام دهد).

هر سکو به‌طور خودکار قالب درست را می‌گیرد (Reel / Short). کپشن شامل سوره، محدودهٔ آیه، قاری، اعتبار عکس و هشتگ‌هاست.

### ذخیره‌سازی — نیازی به نصب MinIO ندارید

ذخیره‌سازی اشیا **فقط برای انتشار** استفاده می‌شود: ریلز در یک باکت S3 آپلود می‌شود تا سرورهای بافر بتوانند آن را از یک **نشانی عمومی** دریافت کنند. اگر فقط به‌صورت محلی رندر می‌کنید (بدون انتشار)، **به هیچ ذخیره‌سازی‌ای نیاز ندارید**.

تنظیمات `MINIO_*` صرفاً اعتبارنامه‌های **استاندارد S3** هستند — هر ارائه‌دهندهٔ سازگار با S3 کار می‌کند، نه فقط MinIO:

| ارائه‌دهنده | نصب؟ | یادداشت‌ها |
|---|---|---|
| **Cloudflare R2** | ❌ | لایهٔ رایگان + باکت‌های عمومی — ساده‌ترین |
| **AWS S3 / Backblaze B2 / Wasabi / DO Spaces** | ❌ | باکت ابری + کلیدهای دسترسی |
| **MinIO خودمیزبان** | ✅ | فقط روی سروری با دامنهٔ عمومی ارزشش را دارد |

⚠️ **نکتهٔ احتیاطی محلی:** بافر از طریق اینترنت عمومی دریافت می‌کند، بنابراین `MINIO_PUBLIC_URL` باکت باید از بیرون دستگاه شما در دسترس باشد. یک MinIO روی `localhost`/شبکهٔ محلی شما **کار نخواهد کرد** (بافر نمی‌تواند به آن برسد) — از یک باکت ابری استفاده کنید، یا MinIO را پشت یک دامنهٔ عمومی میزبانی کنید (مثلاً روی همان دستگاه پنل شما). برنامه در نخستین انتشار باکت را به‌طور خودکار می‌سازد و یک سیاست خواندن عمومی روی آن تنظیم می‌کند، و اشیای قدیمی را پس از `MINIO_RETENTION_HOURS` هرس می‌کند.

## 🐳 استقرار (زمان‌بند همیشه‌روشن + پنل کنترل)

یک فرمان — پایداری در دل آن، هیچ‌چیزی برای راه‌اندازی:

```bash
cp .env.example .env      # fill in your keys (optional — you can also do it in the panel)
docker compose up -d      # scheduler + control panel, on http://localhost:1998
```

همین. در نخستین راه‌اندازی، برنامه **مخزن پیکربندی خود را می‌سازد** در `data/store.json`
(مقداردهی‌شده از `.env` شما) — شما هرگز چیزی نمی‌سازید یا «پیوند» نمی‌دهید. فایل بسته‌بندی‌شدهٔ
`docker-compose.yml` یک والیوم نام‌دار را روی `/app/data` سوار می‌کند، بنابراین تنظیمات، رمز عبور پنل،
صف و تاریخچهٔ شما **به‌طور خودکار در سراسر راه‌اندازی‌های مجدد و بازسازی‌ها پایدار می‌مانند**.

`serve` (فرمان پیش‌فرض) این‌ها را شروع می‌کند:
- یک **پنل کنترل** روی `/` — محافظت‌شده با رمز عبور؛ تنظیمات را مدیریت کنید، یک ریلز
  بسازید/پیش‌نمایش کنید، همین حالا پست کنید، تاریخچه/تحلیل‌ها را مرور کنید و بخش‌ها را صف کنید. هر چیزی را زنده تغییر دهید،
  بدون استقرار مجدد.
- یک **زمان‌بند داخلی** که در هر `PUBLISH_TIMES` در `TZ` شما رندر + منتشر می‌کند؛
- `GET /health` و یک `GET /trigger?key=<TRIGGER_TOKEN>` امن‌شده با توکن برای اسکریپت‌نویسی.

**حالت بدون رابط (Headless):** `tabligh serve --no-panel` را اجرا کنید (یا `PANEL_ENABLED=false` را تنظیم کنید) تا زمان‌بند
به انتشار ادامه دهد در حالی که **هیچ سطح HTTP‌ای در معرض قرار نمی‌گیرد** — ایده‌آل اگر فقط برنامه را
از ترمینال (منوی `tabligh`) مدیریت می‌کنید و نمی‌خواهید یک پنل وب را امن کنید.

**پیکربندی پس از نخستین راه‌اندازی در مخزن قرار دارد** (تا پنل بتواند آن را زنده ویرایش کند). `.env` فقط
یک بار آن را *مقداردهی* می‌کند — برای تغییر چیزها بعداً، از پنل استفاده کنید (یا `tabligh set-password` برای بازنشانی
رمز عبور). `data/store.json` را حذف کنید تا از `.env` دوباره مقداردهی شود.

**روی Coolify / Railway / Fly:** آن را به این مخزن اشاره دهید. اگر **`docker-compose.yml`** را مستقر کنید،
والیوم برای شما ساخته می‌شود — هیچ گام دستی‌ای نیست. اگر از **Dockerfile** ساده استفاده می‌کنید، خط
`VOLUME /app/data` باعث می‌شود بیشتر سکوها آن را به‌طور خودکار پایدار کنند؛ روی Coolify همچنین می‌توانید
یک Persistent Storage سوارشده روی `/app/data` اضافه کنید. متغیرهای محیطی خود را تنظیم کنید و مستقر کنید.

نخستین اجرا بدون CLI؟ فقط پنل را باز کنید — یک **صفحهٔ راه‌اندازی** برای ساخت
رمز عبور شما نشان می‌دهد. ترمینال را ترجیح می‌دهید؟ **`tabligh init`** را برای یک جادوگر تعاملی اجرا کنید.
