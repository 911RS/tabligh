# 🕌 Tabligh

### بَلِّغُوا عَنِّي وَلَوْ آيَةً
_"Sampaikanlah daripadaku, walau satu ayat."_ — Nabi Muhammad ﷺ (Bukhari)

**Hasilkan secara automatik reels Al-Quran yang sinematik dan diselaraskan gaya karaoke, lalu terbitkannya ke TikTok, Instagram, Facebook & YouTube — mengikut jadual, tanpa perlu campur tangan.**

Tidak perlu pilih apa-apa. Penjadual memilih surah + petikan secara rawak, mengambil bacaan yang tepat, memaparkan video menegak dengan penonjolan perkataan demi perkataan di atas latar belakang yang tenang, dan menyiarkannya beberapa kali sehari.

## ✨ Ciri-ciri

- 🎬 **Reels sinematik 1080×1920** — latar belakang foto stok penuh (Pexels/Unsplash) dengan lapisan keterbacaan yang kuat, zarah halus yang hanyut, dan hanyutan Ken-Burns yang perlahan.
- 🎨 **Tiga templat visual** — **classic** (foto + scrim), **glass** (satu kad glassmorphism berkabus yang kekal dengan bentuk gelombang audio langsung), dan **noor** (hangat "Cahaya Ilahi" — lingkaran cahaya keemasan + angka bersalut emas). Tetapkan `TEMPLATE` atau tukar melalui panel/menu.
- 🕋 **Intro Bismillah** — petikan yang bermula pada ayat 1 sentiasa dibuka dengan Bismillah qari itu sendiri (dibaca, dengan suaranya); pilihan untuk menambahkannya di hadapan *setiap* petikan (`BASMALA=always`). At-Tawbah dan Al-Fatihah dikendalikan dengan betul.
- 🎤 **Isian perkataan karaoke** — setiap perkataan menjadi cerah selaras dengan bacaan (kanan→kiri), supaya penonton dapat mengikuti.
- 🖋️ **Tipografi Arab yang autentik** — teks Uthmani penuh dengan *shakl* yang betul dalam muka taip **Mada** yang moden dan kemas; tajuk dalam kaligrafi **Aref Ruqaa**.
- 🎯 **Penyelarasan tepat, tiada AI** — audio datang dari [everyayah.com](https://everyayah.com) sebagai fail setiap ayat, jadi masa setiap ayat adalah tepat dan percuma (tiada transkripsi).
- 🔀 **Pemilihan kandungan automatik** — surah rawak + petikan berturutan rawak (panjang boleh dikonfigurasi); surah pendek dipaparkan sepenuhnya.
- 🌇 **Latar belakang yang selamat dan bertatasusila** — kumpulan 50 kata kunci terpilih (masjid, alam semula jadi, laut, langit…) serta penapis yang membuang mana-mana foto yang mengandungi orang atau apa-apa yang tidak sesuai. Pilih sumber anda: **Pexels, Unsplash, atau folder imej tempatan anda sendiri**.
- 🖥️ **Pusat arahan interaktif** — jalankan `tabligh` (tanpa argumen) untuk UI terminal yang menakjubkan bagi menghasilkan reels, memulakan/menghentikan panel, mengurus baris gilir, melayari sejarah, menyunting tetapan, dan menjalankan pemeriksaan kesihatan. Disetempatkan EN/AR/FR.
- 🎞️ **Outro tanda tangan** — petikan pudar keluar dan satu ṣalawāt (dengan logo anda) meluncur naik di atas babak yang sama, kemudian keseluruhan video pudar menjadi hitam.
- 📤 **Penerbitan berbilang platform** — TikTok, Instagram Reels, Facebook Reels dan YouTube Shorts melalui [Buffer](https://buffer.com), ditogol setiap platform melalui env.
- 🎛️ **Panel kawalan hos sendiri** — UI web dilindungi kata laluan untuk mengurus setiap tetapan, menjana/pratonton/menyiarkan reel, membariskan petikan, dan melayari sejarah + analitik — semuanya langsung, tanpa perlu deploy semula. Disetempatkan (EN/AR/FR, RTL penuh).
- ⏰ **Penjadual tetapkan-dan-lupakan** — proses sentiasa aktif menyiarkan N kali sehari mengikut zon waktu anda.
- 🧹 **Mesra cakera** — fail tempatan dipadam sejurus selepas penyiaran; objek awan dicantas secara automatik.
- 🐳 **Deploy satu bekas** — Dockerfile + berfungsi dengan hebat pada Coolify, Fly, Railway, atau mana-mana hos Docker.

## 🧠 Cara ia berfungsi

```
config / random pick
        │
        ▼
Quran text + translation  ──►  everyayah per-ayah audio (exact timing)
   (alquran.cloud)                       │
        │                                ▼
        └────────────►  TimedAyah[]  ──►  background (Pexels/Unsplash, person-filtered)
                                          │
                                          ▼
              Chromium renders animated frames (karaoke, particles, outro)
                                          │
                                          ▼
                    ffmpeg → MP4 (1080×1920) + recitation + silent outro
                                          │
                                          ▼
              object storage (public URL)  ──►  Buffer  ──►  TikTok / IG / FB / YT
                                          │
                                          ▼
                              cleanup (local now, cloud after ingest)
```

## 🚀 Permulaan pantas (tempatan)

Keperluan: **Node ≥ 20** dan **ffmpeg** pada PATH anda. (Chromium dimuat turun secara automatik oleh Puppeteer.)

```bash
git clone https://github.com/911RS/tabligh.git
cd tabligh
npm install
cp .env.example .env        # fill in what you need (see below)

# Render a specific passage to work/…/reel.mp4 (no publishing)
npm start render -- --surah 112 --from 1 --to 4 --reciter husary --translation en.sahih

# Render a random passage
npm start random

# Everything the CLI can do
npm start
```

`reel.mp4` yang siap (berserta `ir.json` yang bermasa) akan berada di `work/<surah>_<range>_<reciter>__<tag>/`.

## ⚙️ Konfigurasi

Segala-galanya dipacu oleh pembolehubah persekitaran (`.env`). Semuanya adalah pilihan kecuali di mana sesuatu ciri memerlukan kunci.

| Pembolehubah | Tujuan | Lalai |
|---|---|---|
| `TEMPLATE` | Gaya visual reel: `classic` / `glass` / `noor` | `classic` |
| `BASMALA` | Intro Bismillah: `off` (hanya pada ayat 1) / `always` (setiap petikan) | `off` |
| `BACKGROUND_SOURCE` | `auto` / `pexels` / `unsplash` / `local` | `auto` |
| `BACKGROUND_LOCAL_DIR` | Folder imej potret anda sendiri (apabila sumber = `local`) | _(kosong)_ |
| `PEXELS_API_KEY` / `UNSPLASH_ACCESS_KEY` | Latar belakang foto stok | _(tidak ditetapkan → sandaran kecerunan)_ |
| `BUFFER_ACCESS_TOKEN` | Token API Buffer untuk penerbitan | _(tidak ditetapkan → tiada penerbitan)_ |
| `BUFFER_TIKTOK_CHANNEL_IDS` | Id saluran TikTok dipisahkan koma | _(kosong)_ |
| `BUFFER_INSTAGRAM_CHANNEL_IDS` | Id saluran Instagram Reels | _(kosong)_ |
| `BUFFER_FACEBOOK_CHANNEL_IDS` | Id saluran Facebook Reels | _(kosong)_ |
| `BUFFER_YOUTUBE_CHANNEL_IDS` | Id saluran YouTube Shorts | _(kosong)_ |
| `MINIO_*` | Storan serasi S3 (baldi awam yang Buffer ambil daripadanya) | baldi `tabligh`, port `9000` |
| `TZ` / `PUBLISH_TIMES` | Zon waktu + waktu siang untuk siar automatik | `Africa/Tunis` / `07:00,13:00,19:00` |
| `KARAOKE_ENABLED` | Isian perkataan demi perkataan diselaraskan dengan bacaan | `true` |
| `TEXT_FILL_COLOR` | Warna teks yang dibaca (diisi) | `#ffffff` |
| `WATERMARK_ENABLED` / `WATERMARK_HANDLE` | Tera air logo di penjuru (`assets/logo.png`) | `true` / _(kosong)_ |
| `FULL_SURAH_MAX_AYAHS` | Surah sependek ini dipaparkan sepenuhnya | `7` |
| `RANDOM_MIN_AYAHS` / `RANDOM_MAX_AYAHS` | Panjang petikan untuk mod rawak | `5` / `10` |
| `MAX_VIDEO_SECONDS` | Had panjang bacaan (tidak termasuk outro); memangkas ayat penghujung untuk muat (mengatasi min) | `0` _(tiada had)_ |
| `RETENTION_DAYS` / `MINIO_RETENTION_HOURS` | Tetingkap pembersihan | `7` hari / `24` j |
| `PORT` / `TRIGGER_TOKEN` | Pelayan HTTP + rahsia untuk titik akhir pencetus | `1998` / _(tidak ditetapkan → dilumpuhkan)_ |
| `PANEL_ENABLED` | Hidangkan panel kawalan (`false` = tanpa kepala, penjadual sahaja) | `true` |
| `UI_LANG` | Bahasa menu-terminal interaktif (`en` / `ar` / `fr`) | `en` |

Lihat [`.env.example`](.env.example) untuk senarai beranotasi yang penuh. **Nilai-nilai ini menyemai stor pada larian pertama sahaja** — selepas itu, urus tetapan secara langsung dalam panel atau menu `tabligh`.

**Qari:** `husary`, `minshawy`, `abdulbasit`, `hudhaify`, `ayyoub`, `shuraym`, `husary-muallim`, `tunaiji` — atau mana-mana folder [everyayah](https://everyayah.com) mentah. Lihat [`src/quran/reciters.ts`](src/quran/reciters.ts).

**Terjemahan:** mana-mana id edisi [alquran.cloud](https://alquran.cloud), cth. `en.sahih`, `fr.hamidullah`, atau `""` untuk Arab sahaja.

Jalankan **`tabligh`** tanpa argumen dalam terminal untuk membuka menu interaktif — sebuah pusat kawalan lengkap untuk segala-galanya:

```
tabligh                 # opens the menu (in a TTY)
```

- **Jana reel** — rawak atau pilih petikan; dipaparkan secara tempatan (dengan kemajuan langsung), kemudian menawarkan untuk membuka video atau menerbitkannya.
- **Terbitkan sekarang** — jana + terbit dalam satu langkah.
- **Panel kawalan** — **Mula / Henti / Mula semula** panel web sebagai perkhidmatan latar belakang, **buka** ia dalam pelayar anda, atau **jejak lognya** — tiada proses berasingan untuk dijaga.
- **Baris gilir** — tambah/buang petikan yang penjadual mainkan sebelum pilihan rawak.
- **Sejarah & analitik** — jumlah keseluruhan, pecahan mengikut platform, siaran terkini.
- **Tetapan** — bahasa, sumber latar belakang (termasuk folder tempatan), penjadual hidup/mati, jadual, kandungan, saluran, dan kunci API — semuanya digunakan secara langsung.
- **Doktor** — pemeriksaan kesihatan sepintas lalu (ffmpeg, Chrome, kunci, storan, cakera).

Disetempatkan dalam **English / العربية / Français** (tetapkan `UI_LANG` atau tukar dalam Tetapan). Konteks bukan interaktif (paip, Docker, CI) mencetak bantuan klasik sebaliknya, jadi skrip tidak terjejas. Terdapat juga `tabligh menu` (paksakannya) dan `tabligh doctor` (jalankan pemeriksaan kesihatan sahaja).

## 🎛️ Panel kawalan web & CLI

Buka akar aplikasi (`http://localhost:1998`) untuk panel yang dilindungi kata laluan:

- **Larian pertama** memaparkan skrin persediaan untuk mencipta kata laluan anda (atau jalankan `tabligh init` untuk wizard terminal — kini ia berakhir dengan memaparkan URL papan pemuka anda dan menawarkan untuk memulakan panel).
- **Papan pemuka** — status, *Jana sekarang* / *+ terbit* satu klik, pratonton terkini.
- **Jana** — pilih petikan atau pergi rawak, pratonton sebelum ia disiarkan.
- **Tetapan** — jadual (zon waktu + pemilih waktu), kandungan (terjemahan, bilangan ayat, **panjang maksimum**), penjenamaan (karaoke, warna isian, zarah, latar belakang beranimasi, promo outro), id saluran platform, kunci API & storan — digunakan **secara langsung**.
- **Baris gilir** — rancang petikan tertentu; penjadual memainkannya sebelum pilihan rawak.
- **Sejarah / Analitik** — setiap paparan + siaran, jumlah keseluruhan, mengikut platform, log terkini.
- **Bahasa** — tukar panel antara English, العربية (RTL) dan Français.

Log masuk dihadkan kadar (5 percubaan → kunci 15 minit). Tetapkan semula kata laluan dari pelayan dengan
`tabligh set-password <new>` (cth. `docker exec <container> tabligh set-password …`).

Tetapan berada dalam stor dan berkekalan pada volum `/app/data`; `.env` hanya menyemainya pada larian pertama.

### 🌐 Mengakses panel

Aplikasi ini tidak mempunyai domain tersendiri — ia hanya mendengar pada satu port (**`1998`** secara lalai, atasi dengan `PORT`) pada semua antara muka. URL yang anda buka bergantung pada tempat ia berjalan:

| Tempat ia berjalan | URL yang anda buka | HTTPS? |
|---|---|---|
| Komputer anda sendiri (`npm` / tempatan) | `http://localhost:1998` | — (tempatan, tidak mengapa) |
| VPS awan, port mentah didedahkan | `http://<your-server-ip>:1998` | ❌ **tidak** |
| VPS di belakang proksi songsang | `https://yourdomain.com` | ✅ proksi menyediakannya |

- **Secara tempatan**, wizard persediaan mencetak pautan tepat semasa dimulakan (`http://localhost:1998`).
- **Pada VPS**, untuk sampai ke `http://<server-ip>:1998` juga memerlukan firewall / kumpulan keselamatan anda membenarkan masuk `1998`.
- **⚠️ Jangan biarkan port mentah terdedah ke internet.** Panel menghidangkan HTTP biasa, jadi kata laluan log masuk anda akan bergerak tanpa penyulitan. Letakkannya di belakang proksi songsang yang menamatkan TLS:
  - **[Coolify](https://coolify.io)** (disyorkan) — tetapkan domain pada aplikasi dan halakannya ke port `1998`; Traefik Coolify mengendalikan penghalaan **dan** sijil Let's Encrypt secara automatik.
  - **Nginx / Caddy** — `proxy_pass http://127.0.0.1:1998` di belakang domain + sijil anda.

Aplikasi tidak pernah perlu tahu domain awamnya; proksi memiliki domain dan HTTPS dan memajukan ke `1998` secara dalaman.

## 📤 Penerbitan

Penerbitan melalui [Buffer](https://buffer.com), yang mengembang keluar ke setiap platform yang disambungkan.

1. Cipta akaun Buffer dan sambungkan saluran TikTok / Instagram / Facebook / YouTube anda.
2. Tetapkan `BUFFER_ACCESS_TOKEN`, kemudian jalankan `npm start channels` untuk menyenaraikan id saluran anda.
3. Masukkan id ke dalam pembolehubah `BUFFER_*_CHANNEL_IDS` yang sepadan (mana-mana subset — TikTok sahaja pun boleh).
4. `npm start random -- --publish` (atau biarkan penjadual melakukannya).

Setiap platform mendapat format yang betul secara automatik (Reel / Short). Kapsyen termasuk surah, julat ayat, qari, kredit foto, dan hashtag.

### Storan — anda tidak perlu memasang MinIO

Storan objek digunakan **hanya untuk penerbitan**: reel dimuat naik ke baldi S3 supaya pelayan Buffer boleh mengambilnya dari **URL awam**. Jika anda hanya memaparkan secara tempatan (tiada penerbitan), anda **tidak memerlukan storan langsung**.

Tetapan `MINIO_*` hanyalah kelayakan **S3 standard** — mana-mana penyedia serasi S3 berfungsi, bukan hanya MinIO:

| Penyedia | Pasang? | Nota |
|---|---|---|
| **Cloudflare R2** | ❌ | Tahap percuma + baldi awam — paling mudah |
| **AWS S3 / Backblaze B2 / Wasabi / DO Spaces** | ❌ | Baldi awan + kunci akses |
| **MinIO hos sendiri** | ✅ | Hanya berbaloi pada pelayan dengan domain awam |

⚠️ **Amaran tempatan:** Buffer mengambil melalui internet awam, jadi `MINIO_PUBLIC_URL` baldi mesti boleh dicapai dari luar mesin anda. MinIO pada `localhost`/LAN anda **tidak** akan berfungsi (Buffer tidak boleh menjangkaunya) — gunakan baldi awan, atau hoskan MinIO di belakang domain awam (cth. pada kotak yang sama dengan panel anda). Aplikasi mencipta baldi secara automatik dan menetapkan dasar baca-awam pada penerbitan pertama, dan mencantas objek lama selepas `MINIO_RETENTION_HOURS`.

## 🐳 Deployment (penjadual sentiasa aktif + panel kawalan)

Satu arahan — kekekalan termasuk, tiada apa untuk disediakan:

```bash
cp .env.example .env      # fill in your keys (optional — you can also do it in the panel)
docker compose up -d      # scheduler + control panel, on http://localhost:1998
```

Itu sahaja. Semasa but pertama aplikasi **mencipta stor konfigurasinya sendiri** di `data/store.json`
(disemai dari `.env` anda) — anda tidak pernah mencipta atau "memaut" apa-apa. `docker-compose.yml`
yang disertakan melekapkan volum bernama di `/app/data`, jadi tetapan, kata laluan panel,
baris gilir dan sejarah anda **berkekalan merentas mula semula dan bina semula** secara automatik.

`serve` (arahan lalai) memulakan:
- **panel kawalan** di `/` — dilindungi kata laluan; urus tetapan, jana/pratonton
  reel, siar sekarang, layari sejarah/analitik, dan bariskan petikan. Ubah apa-apa secara langsung,
  tanpa deploy semula.
- **penjadual dalaman** yang memapar + menerbitkan pada setiap `PUBLISH_TIMES` dalam `TZ` anda;
- `GET /health` dan `GET /trigger?key=<TRIGGER_TOKEN>` yang dilindungi token untuk skrip.

**Mod tanpa kepala:** jalankan `tabligh serve --no-panel` (atau tetapkan `PANEL_ENABLED=false`) untuk mengekalkan
penjadual menyiarkan sambil mendedahkan **tiada permukaan HTTP langsung** — sesuai jika anda hanya mengurus aplikasi
dari terminal (menu `tabligh`) dan tidak mahu panel web untuk diamankan.

**Konfigurasi berada dalam stor selepas but pertama** (supaya panel boleh menyuntingnya secara langsung). `.env` hanya
*menyemai* ia sekali sahaja — untuk mengubah perkara kemudian, gunakan panel (atau `tabligh set-password` untuk menetapkan semula
kata laluan). Padam `data/store.json` untuk menyemai semula dari `.env`.

**Pada Coolify / Railway / Fly:** halakan ia ke repo ini. Jika anda deploy **`docker-compose.yml`**,
volum dicipta untuk anda — sifar langkah manual. Jika anda gunakan **Dockerfile** biasa, baris
`VOLUME /app/data` membuatkan kebanyakan platform mengekalkannya secara automatik; pada Coolify anda juga boleh
menambah satu Persistent Storage yang dilekapkan di `/app/data`. Tetapkan pembolehubah env anda dan deploy.

Larian pertama tanpa CLI? Cukup buka panel — ia memaparkan **skrin persediaan** untuk mencipta
kata laluan anda. Lebih suka terminal? Jalankan **`tabligh init`** untuk wizard interaktif.
